# 公开范围

本仓库仅包含经过审阅的 MemLab 源码、配置模板、说明、离线测试和 CI。公开文件以 Git index 和 publication-policy.json 的允许范围为准。

## 包含

- 多层记忆策略、上下文预算与组装、异步日志归属、运行有效性检查。
- 外部基础设施配置模板、命令行与服务适配脚本。
- 代码内构造样例的 53 项离线测试。
- 仅源码形式的基准准备适配器；下载须自行显式运行。

## 不包含

真实对话、研究数据、论文附件、原始实验输出、基准下载、模型权重、外部 DeerFlow checkout、数据库内容、环境凭据与原 Git 历史。

生成器输出、服务日志和实验记录默认留在私有忽略目录；这些目录不应提交。

## 发布检查

在没有缓存、数据或生成文件的源码树运行：

```bash
PYTHONDONTWRITEBYTECODE=1 python tools/check_publication.py
```

暂存后还应检查实际 index 中的文件内容：

```bash
PYTHONDONTWRITEBYTECODE=1 python tools/check_publication.py --staged
```

报告写到仓库外。扫描检查文件范围、类型、私密凭据模式与机器路径，不证明作者贡献或数据来源，也不覆盖旧提交历史；新增内容仍需人工核对。

## 研究与工程验证

本仓库为论文相关工程的精简公开版本。测试通过说明对应逻辑分支的断言通过；没有运行论文完整评测、服务端到端集成、在线模型或性能实验。详见 [测试说明](TESTING.md) 与 [第三方来源](../THIRD_PARTY.md)。
