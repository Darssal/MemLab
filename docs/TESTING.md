# 验证边界

```bash
python -m pip install -e ".[dev]"
python -m pytest -q
```

本工程的离线测试覆盖配置/变体映射、上下文策略、L3 指针化、失效与验收记录、答案解析、QA profile、构造运行记录的汇总、服务版本探针的命令生成、并发会话的事件归属，以及 HTTP/服务异常回显不进入诊断记录。测试数据在代码内构造或写入临时目录，不携带原工作区的对话、任务文件或实验记录。

记忆管理测试关闭外部层，或把服务适配器替换为失败桩；Redis 客户端包只用于构造对象。测试不会连接 Redis/Postgres/Qdrant，不调用在线模型，也不运行下载脚本。

单元测试通过只支持这些逻辑分支的断言。以下尚未验证：

- Docker 镜像拉取、启动、健康检查与持久化。
- Redis/Postgres/Qdrant 的真实读写、吞吐和故障恢复。
- DeerFlow 固定版本的服务适配和嵌入式 worker。
- 外部模型 API、费用、基准下载或完整实验矩阵。
- 论文性能数值、跨方案胜负或统计显著性。

主工作区缺失的 `longmemeval/prepare.py` 仅从归档恢复源码以满足 profile 测试；下载依赖已延迟到 `main()`，没有恢复任何数据。

并发测试对 stub 的两个 worker 交错执行，并对 E2E worker 的上下文封装使用模拟任务体。它们验证会话归属逻辑，不代表在线 E2E 流程通过。HTTP 错误只记录状态码或异常类型；外部运行的正常输出、事件记录和服务日志仍应保存在私有忽略目录，公开前另行审查。
